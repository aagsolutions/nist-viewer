# Pure Rust WSQ encoder reference fixtures

The WSQ streams in this folder were generated by `src/wsq/encoder.rs` from the
bundled `test_data/sample.wsq` fingerprint, resized using Lanczos3 to the dimensions
in each filename and encoded at 0.75 bits/pixel with the original PPI.

Each `-reference.png` was produced by independently decoding its WSQ stream using
NBIS 5, upstream commit `3d3b05f0144b706bed56407957bc00779baf2fa5`:
https://github.com/lessandro/nbis/tree/3d3b05f0144b706bed56407957bc00779baf2fa5

That independent check was performed when these fixtures were created. Normal
builds and tests compile and execute only the Rust codec; no C source, FFI,
external codec, or native test dependency is required. Small rounding differences
between independent floating-point implementations are allowed in reference tests.

The test suite checks both the fixed WSQ fixtures against their reference PNGs
and newly encoded images against the same independently generated pixel values.

The NBIS encoder's independently measured mean squared reconstruction errors on
these exact resized inputs at 0.75 bits/pixel were 287.549133 (128×128), 212.184982
(256×256), and 241.971230 (257×193). The pure Rust encoder's quality regression
check allows at most 2% above those reference errors. WSQ is lossy; these values
are a compatibility baseline for this fingerprint, not a certification claim.
